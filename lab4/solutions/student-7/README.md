# Stats

Программа `stats` вычисляет простые статистические показатели для набора целых чисел, переданных через командную строку.

---

## Сборка

Сборка проекта осуществляется через `Makefile`. Все файлы библиотеки `libft` подключаются автоматически.

```bash
make        # Собрать программу
make fclean # Очистить объектные файлы и исполняемый файл
make re     # Полная пересборка
```
После сборки появится исполняемый файл:

./stats
```                 <- здесь уже правильно закрыт блок

Использование

Формат вызова:

```bash
./stats <метрика> <число1> <число2> ... <числоN>
```                 <- блок закрыт, правильно

Поддерживаемые метрики:
Метрика	Описание
min	Минимальное значение
max	Максимальное значение
sum	Сумма всех чисел
avg	Среднее арифметическое (целое, округление вниз)

Примеры
```bash
./stats min 5 3 8 1 9
# Вывод: 1

./stats max 5 3 8 1 9
# Вывод: 9

./stats sum 5 3 8 1 9
# Вывод: 26

./stats avg 5 3 8 1 9
# Вывод: 5
```                 

Ошибки
Неизвестная метрика
```bash
./stats median 1 2 3
# Error: unknown metric
```                 

Недостаточно аргументов
```bash
./stats min
# Error: not enough arguments
```                 

Некорректное число
```bash
./stats sum 1 2 a
# Error: invalid number
```
