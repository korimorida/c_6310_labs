# TxtFile Library — Вариант 3 (Замена подстроки)

Библиотека `txtfile` позволяет работать с текстовыми файлами построчно и выполнять замену подстрок во всём файле. Проект использует собственную библиотеку `libft` и не применяет стандартные функции `<stdio.h>`, `<stdlib.h>` или `<string.h>`.

---

## Сборка

Для сборки проекта используйте `Makefile`:

```
make        # сборка проекта
make clean  # удаление объектных файлов
make fclean # полная очистка
make re     # пересборка
```

После сборки появится исполняемый файл:

```
replace_file
```

---

## Запуск

Программа демонстрирует замену подстроки во всём файле.
Формат запуска:

```
./replace_file <путь_к_файлу> <старое_слово> <новое_слово>
```

Пример:

```
./replace_file data/input.txt cat fox
```

Ожидаемый результат (если input.txt содержит "cat is here", "black cat", "dog and cat"):

fox is here
black fox
dog and fox
