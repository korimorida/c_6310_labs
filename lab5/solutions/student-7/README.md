# Matrix Library

Библиотека matrix реализует работу с динамическими матрицами и их умножение.

---

## Возможности

Библиотека поддерживает:

- создание матрицы (create_matrix)
- удаление матрицы (remove_matrix)
- вывод матрицы (print_matrix)
- умножение двух матриц (mult_matrix)

---  

## Сборка

Проект собирается через Makefile. Также используется библиотека libft.

   
make        # сборка проекта
make clean  # удаление объектных файлов
make fclean # полная очистка
make re     # пересборка
       

После сборки появляется исполняемый файл:

 
./matrix
       

---  



Программа демонстрирует умножение двух матриц:

./matrix
